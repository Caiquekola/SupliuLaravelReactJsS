Desafio
Usando seus conhecimentos em Laravel/ReactJS, precisamos que você implemente melhorias
para a versão 2.0 de um projeto fictício.
O projeto fictício é uma página web que exibe uma lista das 5 músicas mais tocadas da dupla
caipira Tião Carreiro e Pardinho e permite que o usuário sugira novas músicas informando um
link válido no YouTube. O versão 1.0 foi desenvolvida utilizando PHP 8.1 e está disponível no
link https://github.com/jansenfelipe/top5-tiao-carreiro
As melhorias propostas neste desafio consiste em:
1. Separar as aplicações em dois projetos backend e frontend e fazer com que ambos se
comuniquem utilizando uma API REST
2. O backend deve ser construído utilizando o Laravel
3. O frontend deve ser uma Single Page Application utilizando ReactJS
4. Criar testes automatizados utilizando as recomendações de cada framework/biblioteca
5. Utilizar qualquer ferramenta de conteinerização das aplicações
6. Modernizar o layout da aplicação utilizando qualquer biblioteca de estilo que desejar
7. Mostrar também (em menor destaque) a lista da 6ª música em diante, com paginação.
8. Desenvolver uma camada de autenticação para exigir que apenas usuários
autenticados possam sugerir links
9. Desenvolver a funcionalidade de aprovação/reprovação de sugestões onde apenas o
usuário administrador possa acessar e executar.
10. Permitir também que o administrador possa adicionar, editar e excluir links.
11. Documentar no README.md como um novo programador deve proceder para executar
a aplicação em seu ambiente local
Fique a vontade para tomar decisões de banco de dados, design, documentação, enfim ..
Quero que você demonstre seus conhecimentos de backend e frontend explorando todas os
recursos que as ferramentas possuem 😄
